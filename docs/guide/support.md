# Who pays for the runs

Shibbo's maintainer pays for every model run from personal API accounts. A prose run costs a few dollars per model, and the interface, code and report runs cost a little more on top.

## How you can help

- **Run a model with your own key.** [Measure a new model](/guide/measure) has the steps. Open a pull request with the results and shibbo adds the model to the maps.
- **Report a model shibbo missed.** Open an [issue](https://github.com/xvr2e7/shibbo/issues) with the model's name and its release page.
- **Add or correct a tell.** [Add a tell](/guide/add-a-tell) shows the format.
- **Star the repo.** It helps other people find the project.

There is no donation link yet. We may add one if the project grows.
