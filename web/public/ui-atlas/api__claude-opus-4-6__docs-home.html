Features

Everything you need to visualize data

Built from the ground up for performance, accessibility, and developer experience.

🚀

Blazing Fast Rendering

WebGL-accelerated rendering handles millions of data points at 60fps. Falls back gracefully to Canvas 2D.

📐

Declarative API

Describe what your chart should look like, not how to draw it. Clean, composable configuration objects.

🎨

Fully Themeable

Every pixel is customizable. Ship with dark/light themes or create your own with the theme builder.

♿

Accessible by Default

WCAG 2.1 AA compliant. Automatic ARIA labels, keyboard navigation, and screen reader support built in.

📱

Responsive & Touch

Charts automatically resize and reflow. First-class touch gestures for pinch-to-zoom and panning.

🔌

Plugin System

Extend functionality with a powerful plugin API. Annotations, zoom, streaming data — all available as plugins.

Quick Start

Simple, intuitive API

Create beautiful, interactive charts with just a few lines of code. ChartForge's declarative API lets you focus on your data, not boilerplate.

  • Full TypeScript support with auto-completion
  • Tree-shakeable — import only what you use
  • Works with any framework or vanilla JS
  • SSR-compatible with Node.js canvas
  • Export to PNG, SVG, or PDF
app.ts
import { ChartForge } from 'chartforge'; // Create a line chart in one call const chart = new ChartForge('#chart', { type: 'line', data: { labels: ['Jan', 'Feb', 'Mar', 'Apr'], series: [{ name: 'Revenue', values: [44, 55, 67, 83], color: '#6366f1', }] }, options: { animate: true, responsive: true, tooltip: { enabled: true }, } }); // Update data reactively chart.update({ values: [51, 62, 74, 91] });
