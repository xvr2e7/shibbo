Why Plotline

Everything a charting library should be — and nothing it shouldn't.

Plotline focuses on the things that matter in production: performance, accessibility, and a configuration model you can reason about.

Fast by default

Canvas rendering, dirty-rect updates and off-thread layout keep 10,000-point datasets at 60 fps on mid-range hardware.

Themeable with CSS

Every colour, radius and font is a CSS custom property. Swap your brand tokens and the entire chart follows — no re-render required.

Any shape of data

Arrays, objects, streaming deltas, dates, currency and percentages are all first-class. Parsers handle the boring parts.

Accessible by design

Keyboard navigation, ARIA descriptions, screen-reader summaries and a high-contrast palette are built in, not bolted on.

Composable plugins

Annotations, crosshairs, zoom, watermarks and custom legends are official plugins — or write your own with a 20-line hook.

Zero dependencies

12 KB gzipped, no runtime dependencies, no framework lock-in. Works in React, Vue, Svelte, Angular or a plain <script> tag.

Quick start

From zero to a chart in under a minute.

Install the package, describe your data, and you're done. There is no configuration file and no build step.

1

Install the package

Plotline ships as ESM with type declarations and works in any bundler.

Terminal
$ npm install @plotline/core
2

Create a chart

Point the chart() helper at any element.

chart.js
import { chart } from '@plotline/core'

const sales = chart('#sales', {
  type: 'line',
  data: {
    labels: ['Jan', 'Feb', 'Mar'],
    datasets: [{
      label: 'Revenue',
      data: [12, 19, 14]
    }]
  }
})
3

Style it your way

Override CSS variables to match your design system — no JS required.

theme.css
:root {
  --plot-color: #6c5ce7;
  --plot-radius: 12px;
  --plot-font: 'Inter', sans-serif;
}

API reference

A small API surface you'll learn in one read.

Two exported functions and a deeply nested options object. Everything is typed, documented and discoverable through editor intellisense.

options.js
// Every option is optional — these are the defaults.
{
  type: 'line',
  responsive: true,
  animation: { duration: 600, easing: 'easeOutQuart' },
  scales: {
    x: { grid: { display: true } },
    y: { beginAtZero: true }
  },
  plugins: {
    legend: { position: 'bottom' },
    tooltip: { mode: 'index' }
  }
}
