Live Demo 
// Line chart with ChartFlow
const chart = new ChartFlow({
    el: '#chart',
    type: 'line',
    data: {
        labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
        datasets: [{
            label: 'Revenue',
            data: [42, 58, 67, 71, 88, 96],
            color: '#818cf8',
            fill: true,
            smooth: true
        }]
    },
    options: {
        responsive: true,
        animation: {
            duration: 800,
            easing: 'easeOutQuart'
        },
        tooltip: { enabled: true },
        legend: { position: 'top' }
    }
});

Everything you need. Nothing you don't.

Built for developers who want powerful visualizations without the bloat.

Blazing Fast

Renders thousands of data points at 60fps using a highly optimized canvas engine. No virtual DOM overhead.

Responsive by Default

Charts automatically resize and adapt to any container. Perfect for dashboards and mobile-first layouts.

Rich Animations

Bring data to life with smooth transitions, staggered reveals, and spring-based easing curves built in.

Accessible

ARIA labels, keyboard navigation, and high-contrast color schemes. Inclusive by design, not as an afterthought.

11 Chart Types

Line, bar, area, pie, doughnut, radar, scatter, bubble, polar, heatmap, and candlestick — all in one package.

Fully Extensible

Plugin architecture lets you add custom chart types, tooltip renderers, and data transforms seamlessly.

Install in seconds

$ npm install chartflow
