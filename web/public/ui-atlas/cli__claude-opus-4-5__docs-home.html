Why Lumina Charts?

Everything you need to build world-class data visualizations, right out of the box.

Lightning Fast

GPU-accelerated rendering with WebGL. Handle millions of data points without breaking a sweat.

Responsive by Default

Charts automatically resize and adapt to any container. Perfect for dashboards and mobile.

Fully Customizable

Every pixel is configurable. Themes, animations, tooltips, legends—make it truly yours.

TypeScript Native

Built from the ground up with TypeScript. Full type safety and autocomplete support.

Framework Agnostic

Works with React, Vue, Angular, Svelte, or vanilla JavaScript. Your choice.

i18n Ready

Built-in support for localization, RTL layouts, and custom number/date formatting.

Simple, Intuitive API

Get beautiful charts with just a few lines of code.

import { LineChart } from 'lumina-charts'; // Create a responsive line chart const chart = new LineChart({ container: '#chart', data: { labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'], datasets: [{ label: 'Revenue', data: [12, 19, 15, 25, 22, 30], color: '#6366f1', }] }, options: { smooth: true, gradient: true, animation: 'easeOutQuart' } });
