Beautiful Charts, Made Simple

ChartFlow is an open-source charting library that makes it easy to create responsive, interactive visualizations for your data.

Why Choose ChartFlow?

⚡

Lightweight & Fast

Minimal bundle size with maximum performance. Load times that won't slow down your application.

🎨

Fully Customizable

Complete control over colors, fonts, sizes, and animations. Make it yours.

📱

Responsive Design

Charts automatically adapt to any screen size. Perfect mobile experience out of the box.

🔄

Real-time Updates

Update your charts with live data. Smooth animations for every data change.

Quick Start

Get up and running in minutes with just a few lines of code.

import { Chart } from 'chartflow'; const chart = new Chart({ container: '#my-chart', type: 'line', data: { labels: ['Jan', 'Feb', 'Mar', 'Apr'], datasets: [{ label: 'Sales', data: [12, 19, 3, 5], borderColor: '#0066ff', backgroundColor: 'rgba(0, 102, 255, 0.1)' }] } }); chart.render();
