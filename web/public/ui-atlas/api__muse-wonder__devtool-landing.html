// How it works

From install to first fix
in about 90 seconds.

01

Connect read-only

Point Tern at any connection string. It enables pg_stat_statements if needed — nothing to deploy.

$ tern connect $DATABASE_URL
✓ connected · 214 tables · read-only
02

Scan & explain

Tern ranks queries by impact, runs safe EXPLAIN plans, and flags seq scans, N+1s and missing indexes.

$ tern scan --since 24h
⚠ 3 slow · 1 N+1 · 2 missing indexes
03

Fix & verify

Apply the suggested migration, then Tern re-runs the plan and confirms the speedup — in terminal or in CI.

$ tern fix #1 --apply
✓ 2,384ms → 18ms · plan verified
