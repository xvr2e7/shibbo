01 / PATTERN FINGERPRINTING

Automatic N+1 Query Loop Detection

ORMs love hiding 150 identical SELECT queries inside a serializer loop. Tern normalizes query literals into structural AST fingerprints and alerts you when burst concurrency spikes within a single HTTP request trace.

[N+1 DETECTED] Fingerprint #a409c executed 84 times in 112ms window ├─ SELECT * FROM "users" WHERE "users"."id" = $1 ├─ Avg duration: 1.3ms │ Cumulative wall time: 109.2ms └─ Fix: Replace loop lookup with WHERE "users"."id" = ANY($1)
02 / CARDINALITY-AWARE DDL

Smart Composite Index Synthesis

Tern queries pg_stats histograms to order composite index columns by selectivity—placing equality predicates first, range scans second, and INCLUDE payload columns last for Index-Only Scans.

// ZERO-FRICTION DEPLOYMENT

Three ways to attach Tern to your stack.

Whether you're debugging locally on a laptop or auditing a 4TB production RDS instance, Tern adapts to your connection constraints.

MODE 01 // PROXY

Local Wire Proxy

Point your app's DATABASE_URL at Tern's transparent local port. Tern intercepts every query packet with sub-millisecond overhead.

$ tern proxy \ --listen 127.0.0.1:5433 \ --upstream postgres://localhost:5432/app
MODE 02 // STAT_STATEMENTS

Live Telemetry Polling

Connect with a read-only user to production or staging. Tern samples pg_stat_statements or MySQL performance_schema safely.

$ tern top \ --dsn $READONLY_PROD_URL \ --sort total-time
MODE 03 // STDIN PIPE

Log Stream Piping

No direct DB access? Pipe standard Docker, CloudWatch, or Rails/Prisma debug logs directly into Tern for offline plan analysis.

$ kubectl logs deploy/api -f \ | tern parse --dialect postgres

UNIX-first flags & predictable exit codes.

Flag / Option Default Description
--threshold, -t <ms> 50ms Only flag queries whose execution duration or planner estimate exceeds this threshold.
--fail-on-seq-scan false Exit with code 2 if a Sequential Scan occurs on any table exceeding --min-rows (default 10,000).
--detect-n-plus-one true Group normalized AST fingerprints over a sliding 250ms window to surface repeated loop queries.
--suggest-indexes true Synthesize CREATE INDEX CONCURRENTLY statements using live column cardinality statistics.
--format <fmt> tty Output format: tty (interactive TUI), json, sarif, or github-markdown.
