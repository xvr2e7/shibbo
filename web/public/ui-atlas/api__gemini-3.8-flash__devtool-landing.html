Powerful CLI Capabilities

Built for developers tired of unreadable slow-query logs

Passive Socket & eBPF Sniffing

No need to add heavy database extensions, alter postgresql.conf, or reboot your production database. Tern attaches directly to local unix sockets or packet streams with minimal overhead (<0.8% CPU).

$ tern attach --pid $(pgrep postgres) --min-duration 100ms

ORM Source Tracer

Translates opaque SQL back into your Prisma, Drizzle, ActiveRecord, or Django model calls and pinpoint file line numbers using query comment tags.

↳ app/models/tenant.py:112
.filter(active=True).prefetch(...)

Index Virtualizer

Uses hypothetical indexes (HypoPG) to test suggestions before committing disk space. Simulates cost drops without touching tables.

Rich Interactive Terminal UI

Built with Bubbletea and Charm. Navigate slow queries by latency percentiles, drill into buffer cache hit ratios, and export clean Markdown reports directly from your tmux session.

[↑/↓] Select Query   [E] Explain Tree   [I] Suggest Index   [D] Copy DDL
Zero To Optimizing

How Tern fits into your terminal workflow

STEP 01

Point and run

Pass your local connection URL or tail a running Docker service. No daemons to configure or cloud telemetry accounts required.

STEP 02

Find the culprit

Tern aggregates queries with normalized signatures and ranks bottlenecks by total time spent, lock delay, and I/O pressure.

STEP 03

Apply clean fixes

Generate copy-pasteable CREATE INDEX CONCURRENTLY statements and rewritten queries with estimated speedups.

Block query regressions in Pull Requests

Drop tern-action into GitHub Actions. If a new schema change or ORM query triggers a sequential scan on a table exceeding 100k rows, Tern fails the build and leaves a helpful comment.
