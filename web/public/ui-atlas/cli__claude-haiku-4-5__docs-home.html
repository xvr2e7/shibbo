Quick Start

Get up and running in under 5 minutes

Installation

npm install chartos

Basic Usage

import ChartOS from 'chartos'; const chart = new ChartOS('#container', { type: 'line', data: { labels: ['Jan', 'Feb', 'Mar'], datasets: [{ label: 'Sales', values: [12, 19, 3] }] } });
