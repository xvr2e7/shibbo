Tern is a command-line tool that analyzes your database queries and identifies performance bottlenecks in seconds.

Features

Everything you need to optimize

Tern gives you deep insights into your database performance without complex setup or configuration.

⚡

Real-time Analysis

Monitor your queries as they run and get instant feedback on performance issues.

🔍

Smart Detection

Automatically identifies N+1 queries, missing indexes, and full table scans.

📊

Impact Scoring

Prioritize fixes based on how much each query affects your application's performance.

💡

Fix Suggestions

Get actionable recommendations with ready-to-run SQL commands to optimize queries.

🔗

Multi-Database Support

Works with PostgreSQL, MySQL, MariaDB, and SQLite out of the box.

🔒

Privacy First

All analysis happens locally. Your data never leaves your machine.

How It Works

Three steps to faster queries

1

Connect

Point Tern at your database with a simple connection string. No agents or daemons required.

2

Analyze

Tern examines your query logs and execution plans to identify bottlenecks.

3

Optimize

Apply the suggested fixes and watch your query times drop dramatically.

Get Started

Install in seconds

Available via Homebrew, npm, or as a standalone binary.
