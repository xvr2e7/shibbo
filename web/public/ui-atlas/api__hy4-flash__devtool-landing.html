Everything you need to optimize

Blazing Fast

Written in Rust, Tern adds less than 1% overhead to your database. Stream logs and analyze patterns without slowing down your app.

Pinpoint Bottlenecks

Automatically groups similar queries, tracks execution plans, and highlights missing indexes or N+1 problems as they happen.

Actionable Insights

Don't just find the problem—fix it. Tern suggests optimized query rewrites and necessary indexes based on your specific schema.

Universal Support

Out-of-the-box support for PostgreSQL, MySQL, MongoDB, and SQLite. Point Tern at your connection string and start hunting.

Up and running in minutes

01

Install the CLI

Get Tern on your machine with a single command. Available via Homebrew, APT, or our install script for all major platforms.

$ brew tap tern-dev/tern
$ brew install tern
==> Downloading and installing tern...
==> ✓ tern 1.4.0 installed
02

Point & Hunt

Connect directly to your database or pipe your existing logs. Tern immediately begins analyzing query telemetry in real-time.

$ tern hunt --db "postgres://user:pass@localhost/db"
Analyzing pg_stat_statements...
Scanning active queries... █
