Quick Start

Get up and running in seconds

1. Install

npm install chartforge

2. Create Your First Chart

import { Chart } from 'chartforge'; const chart = new Chart('#chart', { type: 'bar', data: { labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May'], datasets: [{ label: 'Revenue', data: [45, 62, 38, 71, 89] }] } });

3. Explore Chart Types

ChartForge supports: Line, Bar, Pie, Doughnut, Scatter, Area, Radar, Bubble, Mixed, and more.
