Features

Built for the terminal, not another tab

Everything you need to diagnose query performance, without shipping logs anywhere.

Real-time query ranking

Continuously ranks live queries by total time, mean latency, and call frequency so you always see what matters most right now.

Zero instrumentation

Reads directly from pg_stat_statements, the MySQL performance schema, or SQLite's query log. No app code changes.

EXPLAIN plan diffing

Automatically runs EXPLAIN on your worst offenders and diffs plans before and after an index change so you can confirm the fix.

Index suggestions

Heuristics trained on common access patterns surface missing indexes, redundant ones, and queries that skip them entirely.

CI-friendly exit codes

Run tern check in CI to fail builds when a migration introduces a query slower than your budget.

Configurable thresholds

Set latency and call-count budgets per environment in a single tern.toml file, checked into your repo.

How it works

From install to insight in under a minute

No agents to deploy, no sidecars, no new infrastructure.

1

Point it at your database

Give Tern a connection string with tern connect $DATABASE_URL. It auto-detects Postgres, MySQL, or SQLite.

2

Scan and rank

Run tern scan to pull query stats and rank every statement by total and average execution time.

3

Fix and verify

Apply a suggested index, then re-run tern explain to confirm the plan actually improved.
