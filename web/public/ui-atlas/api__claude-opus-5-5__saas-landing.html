Questions

The things people ask first.

Do we need to tag tickets first?

No. Relay reads the full conversation and groups tickets by the underlying problem. If you already use tags, Relay can use them as extra context, but it doesn't depend on them.

How long until the first report?

Right away. When you connect, Relay backfills the last eight weeks and sends a first report within the hour, so you start with trends instead of a blank page.

What happens to our customer data?

Access is read-only. Personal information is redacted before analysis, data is encrypted at rest and in transit, and it's never used to train shared models. You can delete everything from settings at any time.

Can we get the report more often than weekly?

Yes. On Team and Enterprise you can add a daily digest or a real-time alert when a theme spikes, for example right after a release. The weekly report stays the main event.

Which languages does it read?

Over 40, including all major European and Asian languages. Tickets in different languages about the same problem are grouped together, and the report is written in yours.
