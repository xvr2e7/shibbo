Why Arcplot

Everything you need. Nothing you don't.

Designed for dashboards, data journalism, and product analytics — scaling from a single sparkline to millions of points.

Blazing fast

Canvas, SVG, and WebGPU renderers. Render 1M+ points at 60fps with automatic decimation.

Composable

Mix marks, scales, and axes like building blocks. Layer a line over bars over annotations.

Smooth animation

Spring-based transitions that interpolate data, not pixels. Updates feel natural by default.

Accessible

Keyboard navigation, ARIA descriptions, and screen-reader data tables generated automatically.

TypeScript first

Strict, inferred types for every option. Your editor knows your config better than you do.

Framework agnostic

Use it vanilla, or with official React, Vue, Svelte, and Solid bindings.

Quick start

Your first chart in under a minute.

1

Install the package

Via npm, pnpm, yarn — or drop in a single script tag from the CDN.

2

Add a container

Any element with a size works. Charts are responsive by default.

3

Describe your chart

Pass data and a type. Arcplot infers scales, axes, and colors.

Read the full guide → 
import { Chart } from 'arcplot';

const data = [
  { month: 'Jan', users: 1240 },
  { month: 'Feb', users: 1890 },
  { month: 'Mar', users: 2410 },
];

new Chart('#chart', {
  type: 'line',
  data,
  x: 'month',
  y: 'users',
  curve: 'smooth',
  tooltip: true,
}); // that's it ✨
import { LineChart } from '@arcplot/react';

export default function Users({ data }) {
  return (
    <LineChart
      data={data}
      x="month"
      y="users"
      curve="smooth"
      tooltip
    />
  );
}
