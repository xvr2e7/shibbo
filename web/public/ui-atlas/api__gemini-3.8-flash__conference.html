The Concept

Frontend is no longer just JavaScript in a viewport.

The modern web application stack is converging around edge rendering, server components, compiled WebAssembly UI engines, intelligent client caching, and declarative styling primitives.

LISBOA.FE gathers engineers building the frontier of browser applications. We eschew basic introductory intros in favor of real benchmarks, architectural post-mortems, and live interactive production demos — accompanied by 25°C autumn Lisbon breeze and artisanal pasteis de nata.
