Find Slow Queries
Before Your Users Do

Tern is a command-line tool that analyzes your database logs and identifies performance bottlenecks in seconds.

Get Started View on GitHub
$ tern analyze --db postgres --log app.log
Analyzing database queries...
✓ Scanned 12,450 queries in 0.8s
 
⚠ Found 23 slow queries (>100ms)
 
Top offenders:
1. SELECT * FROM users WHERE email LIKE... (avg: 2.4s, 145 calls)
2. JOIN orders ON users.id = orders.user... (avg: 1.8s, 89 calls)
3. UPDATE sessions SET last_active = ... (avg: 0.9s, 234 calls)
 
✓ Report saved to tern-report.html

Why Tern?

⚡

Lightning Fast

Analyze thousands of queries in seconds. Built with performance in mind using efficient parsing algorithms.

🎯

Pinpoint Issues

Identifies slow queries, N+1 problems, missing indexes, and other common performance bottlenecks automatically.

🔌

Multi-Database Support

Works with PostgreSQL, MySQL, MongoDB, and more. Parse any log format with custom adapters.

📊

Beautiful Reports

Generate detailed HTML reports with charts, statistics, and actionable recommendations.

🔍

Deep Insights

See query patterns, execution times, call frequencies, and correlations across your application.

🛠️

CI/CD Ready

Integrate into your pipeline with exit codes, JSON output, and configurable thresholds.

How It Works

1

Point to Your Logs

Tell Tern where your database logs are located or pipe them directly.

2

Automatic Analysis

Tern parses queries, measures performance, and identifies patterns.

3

Get Insights

Review prioritized issues with recommendations on how to fix them.

4

Optimize & Ship

Apply fixes and verify improvements in your next analysis.
