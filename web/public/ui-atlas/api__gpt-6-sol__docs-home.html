A quick start

Just a canvas and a few lines of JavaScript. It really is that simple.

Full guide ↗
JavaScript
import Chart from 'chart.js/auto'

new Chart(document.getElementById('myChart'), {
  type: 'bar',
  data: {
    labels: ['January', 'February', 'March'],
    datasets: [{ label: 'Sales', data: [12, 19, 15] }]
  }
})

Install with npm install chart.js and you're ready to go.
