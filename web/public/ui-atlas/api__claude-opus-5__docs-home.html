Why Plotline

Everything you need, nothing you don't

One tiny core, a predictable data contract, and escape hatches everywhere. No wrapper around a wrapper around D3.

Fast by default

Incremental diffing, canvas & WebGL fallbacks, and zero layout thrash. 100k points render in under 16 ms.

Themed with CSS

Every colour, radius and font is a custom property. Dark mode is --pl-bg, not a config rewrite.

Streaming data

chart.push() appends to a rolling window with interpolated transitions — ideal for dashboards.

Accessible output

Charts emit a keyboard-navigable data table, ARIA roles and respect prefers-reduced-motion.

SSR & static export

Render to a string on the server, hydrate on demand, or export crisp SVG/PNG for reports and emails.

Composable marks

Layer lines, bars, bands and annotations on shared scales. Drop into raw SVG whenever you need to.

Quick start

Your first chart in three steps

Works with any bundler, or straight from a CDN with no build step at all.

1

Install

Grab the package, or skip ahead with the ESM build from a CDN.

# package manager
npm i plotline

# or no build step
import * as pl from
  'https://esm.sh/plotline@3'
2

Add a mount point

Any element works. Plotline reads its box and stays responsive.

<div id="chart"
     style="height:280px"></div>
3

Render

Pass data and marks. Call update() whenever the data changes.

import { chart, line } from 'plotline'

const c = chart('#chart', {
  data: rows,
  marks: [line('date', 'value')]
})
