Developer Experience

Simple API, powerful output

Create publication-quality charts in a few lines. The declarative config handles layout, scales, and animations so you can focus on your data.

  • Auto-scaling axes with smart tick formatting
  • Built-in interpolation: linear, cardinal, step, monotone
  • Annotations, tooltips, and crosshairs out of the box
  • Plugin system for custom renderers and interactions
chart.ts 
import { LineChart, TimeScale } from 'carta-charts';

const chart = new LineChart({
  target: document.getElementById('chart'),
  data: {
    labels: months,
    datasets: [
      {
        label: 'Revenue',
        values: revenue,
        color: '#6366f1',
        fill: true,
      },
    ],
  },
  scales: {
    x: new TimeScale({ granularity: 'month' }),
  },
  animate: true,
});
