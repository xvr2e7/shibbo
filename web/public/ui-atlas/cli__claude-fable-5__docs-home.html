Quickstart

Your first chart in under a minute

Describe your data and marks; Plotkit handles scales, axes, tooltips, and resizing.

1

Install the package

Run npm install plotkit, or load it from a CDN with a single <script> tag — no build step required.

2

Add a container

Any element works: <div id="app"></div>. Charts are responsive by default and re-render on resize.

3

Describe your chart

Pass data and a list of marks. Scales, axes, and tooltips are inferred — override anything when you need to.

chart.jsESM
import { plot, line, area } from "plotkit";

const data = await fetch("/api/usage.json")
  .then(r => r.json());

plot("#app", {
  data,
  x: "month",
  marks: [
    area({ y: "web", opacity: 0.15 }),
    line({ y: "web", stroke: "teal" }),
    line({ y: "mobile", stroke: "indigo" }),
  ],
  tooltip: true,  // keyboard-navigable
});
Why Plotkit

Small library, serious charts

Everything you need for production dashboards — and nothing you don't.

⚡

Tiny & fast

9 kB gzipped with zero dependencies. Renders 50k points at 60 fps with automatic canvas fallback.

🧩

Declarative marks

Compose lines, areas, bars, dots, and annotations into any chart. No chart-type lock-in.

♿

Accessible by default

Keyboard-navigable tooltips, ARIA descriptions, and colorblind-safe default palettes.

🎨

Themeable

Style with CSS variables or design tokens. Dark mode works out of the box.

⚛️

Framework adapters

First-party bindings for React, Vue, and Svelte, plus a vanilla API that works anywhere.

📦

SSR ready

Render static SVG on the server, then hydrate interactivity on the client — or don't.
