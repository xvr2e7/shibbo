Why LuminaCharts?

Designed from the ground up to provide a superior developer experience and blazing fast performance for your users.

Blazing Fast

Optimized rendering pipeline using HTML5 Canvas ensures smooth animations and interactions even with large datasets.

Framework Agnostic

Use it with Vanilla JS, React, Vue, Svelte, or Angular. Wrappers are available for all major frameworks.

Highly Customizable

Every element can be styled. Extensive configuration options allow you to match your brand's design system perfectly.

Responsive by Default

Charts automatically resize and redraw when the container size changes, maintaining aspect ratios perfectly.

Quick Installation

Get up and running in less than a minute. Choose your preferred package manager or use a CDN.

Via NPM

terminal 
npm install luminacharts
# or
yarn add luminacharts

Via CDN

index.html 
<!-- Add to your head or body -->
<script src="https://cdn.jsdelivr.net/npm/luminacharts@2/dist/lumina.min.js"></script>

Hello World Example

Creating your first chart is as simple as defining a canvas and passing your data config.

app.js 
import { Chart } from 'luminacharts';

const ctx = document.getElementById('myChart');

new Chart(ctx, {
  type: 'bar',
  data: {
    labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May'],
    datasets: [{
      label: 'Monthly Revenue',
      data: [12000, 19000, 15000, 22000, 28000],
      backgroundColor: '#4f46e5',
      borderRadius: 6
    }]
  },
  options: {
    responsive: true,
    scales: {
      y: { beginAtZero: true }
    }
  }
});
