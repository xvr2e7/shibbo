FAQ

Questions, answered.

Which help desks does Relay support?

Relay has native integrations with Zendesk, Intercom, Help Scout, and Front. If you use something else, our open API and CSV import cover most custom setups.

How does Relay actually cluster tickets?

Relay reads the content of each conversation and groups it with semantically similar tickets — not just by keyword — so "checkout won't load" and "payment page is frozen" land in the same theme.

Can the report go to Slack instead of email?

Yes. You can deliver the weekly report to email, a Slack channel, or both, and push high-priority issues straight into Linear or Jira as tickets.

Is our customer data secure?

Yes. Relay is SOC 2 Type II compliant, encrypts data in transit and at rest, and never uses customer ticket content to train shared models.

Can we customize what goes in the report?

Absolutely — you can choose which theme categories to track, set custom spike thresholds, and reorder sections to match how your team reviews insights.
