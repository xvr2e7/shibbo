Optimized for high-frequency data updates with a virtualized rendering engine that handles thousands of points effortlessly.

Change colors, fonts, and shapes using a simple JSON configuration or CSS variables for complete design control.

♿ Accessible

Built-in ARIA support, screen reader compatibility, and keyboard navigation for all interactive chart elements.

Start in seconds

Our API is designed to be intuitive. Define your data, pick a chart type, and you're done.

// Import the library
import { Chart } from 'chartly';

const myChart = new Chart({
  type: 'line',
  data: {
    labels: ['Jan', 'Feb', 'Mar'],
    datasets: [{
      label: 'Users',
      data: [12, 19, 3]
    }]
  },
  options: { responsive: true }
});
