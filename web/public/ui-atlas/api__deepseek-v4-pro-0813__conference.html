Two Days.

Frontend Summit Lisbon brings together the global frontend community for two intensive days of cutting-edge content. Whether you're a seasoned architect, a curious developer or a design engineer, you'll leave with actionable insights and new connections.

From the latest in React Server Components and edge rendering to design system strategy, accessibility engineering and AI-driven UI — our carefully curated program covers the full spectrum of modern frontend development.
