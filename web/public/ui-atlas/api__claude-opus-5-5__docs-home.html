Why Plotline

Everything you need, nothing you don't.

A small core with tree-shakeable modules. Pay only for the charts you actually ship.

Blazing performance

Render 1M+ points at 60fps with the WebGPU backend. Automatic downsampling keeps SVG output lean.

Composable grammar

Layer marks, scales and transforms like building blocks. Build custom visualizations without forking.

TypeScript-first

Fully typed APIs infer your data shape, so field names autocomplete and typos fail at compile time.

Accessible by default

ARIA roles, keyboard navigation, screen-reader summaries and color-blind-safe palettes out of the box.

Streaming & real-time

Push data with chart.append() and get smooth transitions without re-rendering the world.

Themeable everywhere

Style with CSS variables, design tokens or a theme object. Dark mode follows your app automatically.

Quick start

Your first chart in under a minute.

  1. Install the package

    Use your favourite package manager, or drop in the CDN build. No peer dependencies.

  2. Point it at a container

    Any element works: a CSS selector, an HTMLElement, or a framework ref.

  3. Describe your data

    Map fields to channels like x, y and color. Plotline picks sensible scales and axes.

  4. Ship it

    Responsive, accessible and SSR-safe. Read the core concepts next.

import { Chart, line, dot } from 'plotline';

const data = [
  { day: 'Mon', visits: 1240 },
  { day: 'Tue', visits: 1580 },
  { day: 'Wed', visits: 1320 },
  // …
];

new Chart('#app', {
  data,
  marks: [
    line({ x: 'day', y: 'visits', curve: 'natural' }),
    dot({ x: 'day', y: 'visits', r: 4 }),
  ],
  axis: { y: { grid: true, format: '~s' } },
  tooltip: true,
}).render();
import { LineChart } from '@plotline/react';

export default function App() {
  return (
    <LineChart
      data={data}
      x="day"
      y="visits"
      curve="natural"
      dots
      tooltip
      height={320}
    />
  );
}

// Works with Server Components. The chart
// hydrates on the client only when visible.
<div id="app"></div>
