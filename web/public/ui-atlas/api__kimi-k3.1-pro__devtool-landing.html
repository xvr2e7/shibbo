Which databases does Tern support?
Tern supports PostgreSQL, MySQL, and SQLite. It works with local databases and managed services, provided you can connect using standard database credentials.
Does Tern require an agent or a server?
No. Tern is a single CLI binary. Start a local watch session with tern watch, inspect the results in your terminal, and shut it down when you’re done.
Will Tern change my database?
Watching is read-only. Tern can suggest an index or query rewrite, but it never applies migrations or modifies your schema automatically.
Can I use Tern with production data?
Yes. Use a read-only role and enable value redaction when needed. Tern’s local-first mode keeps analysis on your machine, and reports are only exported when you explicitly ask.
Is Tern free?
Yes. The Tern CLI is free, open source, and MIT licensed. You can inspect the code, open an issue, or contribute on GitHub.
