§ 02 · Quickstart

Your first chart
in ninety seconds.

01

Install

A single package, no peer requirements. npm install ordinate — or skip the build step entirely and import from a CDN.

02

Import only what you draw

Tree-shakeable ESM: the core is chart(), the marks are one-liners, everything else is opt-in.

03

Render into any element

Ordinate mounts plain SVG nodes you can style, inspect and animate with ordinary browser tools. No shadow DOM, no iframe, no surprises.

The figure at the top of this page is running the program on the right — flip the mark switch above it and watch line 8 follow.

// revenue.js — the figure above is running this file
import { chart, lineY, areaY, barY } from 'ordinate';

const plot = chart('#revenue', {
  x: 'month',
  y: { domain: [0, null], nice: true },
});

plot.render(lineY(revenue, {
  stroke: 'accent',
  smooth: true,  // try areaY / barY above
}));
<div id="revenue"></div>

<script type="module">
  import { render } from './revenue.js';
  render(); // plain SVG out — inspect it in devtools
</script>

§ 04 · Specifications

Small enough
to read in an afternoon.

No themes to download, no “enterprise” tier, no telemetry. The whole library is about 1,400 lines of readable TypeScript — which is exactly the point.

Bundle size
14.8 kB min+gzip, fully tree-shakeable ESM
Dependencies
0 — nothing in the lockfile but the lockfile
Renderer
SVG 1.1, with an optional canvas adapter for 10k+ point series
Frameworks
None required; adapters for React, Svelte and Vue are opt-in
TypeScript
Types shipped in the package — no @types twin
Accessibility
Keyboard-navigable marks, ARIA table fallback for every chart
Styling
Plain SVG — style it with the CSS you already have
License
MIT, since the first commit
Current release
v3.2.0 — semver, changelog per release
