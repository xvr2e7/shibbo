Tern

Find slow queries
before they find you

Tern analyzes your database logs and identifies performance bottlenecks in seconds. Know what's slowing down your app.

Installation
npm install -g tern-db

Also available via Homebrew, pip, and Docker

Built for speed and clarity

Instant Analysis

Parse millions of log entries in seconds. Get immediate insights into query performance without waiting for exports or manual review.

Multi-Database Support

Works with PostgreSQL, MySQL, MongoDB, and more. Unified interface for analyzing logs across your entire stack.

Smart Prioritization

Automatically ranks queries by impact. Focus on what matters: the slowest queries with the highest frequency.

Rich Output Formats

View results in terminal, export to JSON, or generate HTML reports. Integrate with your existing monitoring and alerting tools.

Pattern Recognition

Detects query patterns and groups similar queries. See which templates are causing problems, not just individual statements.

Privacy First

All analysis happens locally. Your database logs never leave your machine. No external services, no data collection.
