Why use Tern?

Multi-Database Support

Works seamlessly with PostgreSQL, MySQL, and SQLite. Just point Tern to your connection string or query log file and let it run.

Automated EXPLAINs

Tern automatically runs EXPLAIN ANALYZE on your slowest queries and translates the complex output into human-readable advice.

CI/CD Integration

Add Tern to your GitHub Actions or GitLab CI. Configure it to fail the build if it detects N+1 queries or queries exceeding a latency threshold.

Blazing Fast

Written in Rust, Tern parses thousands of query logs per second with virtually zero memory overhead.

Zero Configuration

No agents to install, no complicated config files. Download the binary and start analyzing your local or staging database immediately.

Export Formats

Output findings directly to the terminal, or export to JSON, CSV, or HTML to share with your team or integrate with other tools.

Catch issues in PRs, not production.

$ tern ci --threshold=500ms --fail-on-n-plus-one ./test.log
