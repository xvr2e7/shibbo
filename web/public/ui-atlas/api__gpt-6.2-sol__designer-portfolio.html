Orbit / Dashboard concept

Clarity for busy teams

Orbit explores how a project dashboard can help team leads decide where to spend their attention before a weekly check-in.

Start with what needs a decision

The overview separates completed work, work in progress, and items that need attention. Leads can go straight to a blocked project without scanning every status update.

Keep trends in context

A compact activity chart sits beneath the project counts. It provides a sense of momentum without taking priority over the work that needs a closer look.
Still / Mobile app concept

A moment to pause

Still is a concept for people who want a short break without browsing a library of sessions or committing to a daily streak.

Make it easy to begin

The home screen offers one short breathing session and shows its duration before you start. An evening wind-down is there if you want it, but it doesn’t compete with the main action.

Let people set their own pace

The breathing guide pairs a visual rhythm with simple written cues. There’s no score to check afterward, just the option to finish or go again.
