Quickstart in 30 Seconds

          
Install the core engine or pick a reactive framework wrapper. All primitives share the same declarative schema.

        


        
        

          

            

              
              
              
              
            

            
          

          
npm install @plotcraft/core @plotcraft/react

        


        
        

          

            

              
              
              
            

            
          

          
import { createChart, AreaSeries, TimeScale } from '@plotcraft/core';

const chart = createChart('#telemetry-root', {
  height: 320,
  scaleX: TimeScale({ utc: true }),
  crosshair: { snap: 'nearest-x' },
  series: [
    AreaSeries({
      dataKey: 'latency_p99',
      curve: 'monotoneX',
      stroke: '#22D3EE',
      fillOpacity: 0.22,
    })
  ]
});

chart.setData(streamBuffer);

Core Configuration API

          
Every PlotCraft instance accepts a strongly-typed configuration object with reactive scale bindings.

        


        

          

            
              

                Property
                Type
                Default
                Description
              

            
            
              

                scaleX / scaleY
                ScaleDefinition
                LinearScale()
                Defines domain-to-range mapping. Supports TimeScale, LogScale, BandScale, and QuantileScale.
              

              

                downsample
                'lttb' | 'minmax' | false
                'lttb'
                Largest-Triangle-Three-Buckets decimation keeps visual fidelity while capping DOM nodes to viewport pixel width.
              

              

                renderer
                'svg' | 'canvas' | 'hybrid'
                'hybrid'
                Renders crisp vector axes/annotations in SVG while offloading high-density series (>5,000 points) to Canvas2D/WebGL.
              

              

                springConfig
                { stiffness, damping }
                { 220, 26 }
                Physics-driven morphing when datasets mutate or coordinate domains rescale.
              

              

                a11y
                A11yOptions
                { keyboardNav: true }
                Automatically synthesizes ARIA live-regions and roving tabindex navigation across data points.
