Simple API

From zero to chart in minutes

ChartFlow has a minimal, intuitive API. Import the library, pass your data, and get a beautiful interactive chart — no complex configuration needed.

1
Install the package
Works with npm, yarn, pnpm, or via CDN.
2
Define your data
Pass any JavaScript array — no special format required.
3
Render and interact
Tooltips, zoom, pan, and animations included out of the box.
import { ChartFlow } from 'chartflow'; // Define your data const data = { labels: ['Jan', 'Feb', 'Mar', 'Apr'], datasets: [{ label: 'Revenue', data: [4200, 6800, 5900, 8100], color: '#58a6ff', fill: true, }] }; // Create the chart const chart = new ChartFlow('#myChart', { type: 'line', data, options: { smooth: true, animate: true, tooltip: 'auto', } }); // Update data live chart.update({ data: newData });
Why ChartFlow

Everything you need to visualize data

Built from the ground up for performance, accessibility, and developer experience.

⚡
Blazing Fast
WebGL-accelerated renderer handles millions of data points at 60fps. Canvas fallback included for legacy browsers.
🎨
Fully Themeable
Token-based theming system with built-in light and dark modes. Create pixel-perfect charts that match your brand.
♿
Accessible by Default
WCAG 2.1 AA compliant. Full keyboard navigation, ARIA labels, and screen reader support built in.
🧩
Plugin Architecture
Extend ChartFlow with a rich plugin ecosystem. Zoom, annotations, data export, and more as optional add-ons.
📱
Responsive & Touch
Charts adapt to any screen size automatically. Pinch-to-zoom and swipe gestures work on all touch devices.
🔷
TypeScript Native
Full type definitions ship with the library. Enjoy autocomplete, inline docs, and compile-time safety in every project.

Installation

Start in seconds

Install via your favorite package manager or drop a script tag into your HTML.

npm npm install chartflow
yarn yarn add chartflow
pnpm pnpm add chartflow
CDN <script src="https://cdn.chartflow.dev/v4/chartflow.min.js"></script>

No build step required. Works with vanilla JS, React, Vue, Svelte, and Angular.
