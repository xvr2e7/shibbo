Why Plotix

Everything you need, nothing you don't

A thoughtfully designed API focused on performance, accessibility, and developer happiness.

Lightweight & fast

9.4kb gzipped core with a WebGL-accelerated renderer for buttery smooth 60fps charts, even with 100k+ points.

Framework agnostic

First-class bindings for React, Vue, Svelte, and Angular — or drop it straight into vanilla JS.

Fully typed

Written in TypeScript from day one, with rich autocompletion and inline docs for every option.

Rich interactions

Tooltips, zoom, pan, brushing, crosshairs and animated transitions — built in and fully customizable.

Themeable

Ship with 12 built-in themes or craft your own with a simple, token-based design system.

Accessible by default

Keyboard navigation, ARIA live regions, and screen-reader-friendly data tables out of the box.

Quick start

Up and running in under a minute

Install via your favorite package manager, or drop in a CDN script — no build step required.

Terminal 
npm install plotix
yarn add plotix
pnpm add plotix
<script src="https://cdn.jsdelivr.net/npm/plotix@3/dist/plotix.min.js"></script>
