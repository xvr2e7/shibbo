Why Plotline

    
Everything you need, nothing you have to fight.

    
Sensible defaults that look good out of the box, with escape hatches at every layer when you need full control.

  

  

    

      

      
Declarative by design

      
Describe what you want, not how to draw it. Pass a plain object, get a chart. Update the spec and Plotline diffs and animates the transition.

    

    

      

      
Fast at any scale

      
Swap renderers with one line. Canvas for most charts, SVG when you need DOM access, WebGL when you have millions of points.

    

    

      

      
Accessible out of the box

      
Every chart ships with keyboard navigation, screen-reader descriptions, and a generated data table. WCAG 2.2 AA color palettes included.

    

    

      

      
Responsive and themeable

      
Charts resize with their container via ResizeObserver. Theme with CSS custom properties or a JS object, including dark mode and print.

    

    

      

      
Interactions built in

      
Tooltips, crosshairs, brushing, zoom and pan, legend toggling, and synced charts work with a single option each. Compose or write your own.

    

    

      

      
Typed end to end

      
Written in TypeScript with strict types for every option. Your editor autocompletes chart specs and catches mistakes before they render.

Quick start

    
From zero to chart in under a minute.

    
Plotline works with any framework or none at all. Pick a step to see the code.

  

  

    

      

        
1

        
Install the package
Available on npm, or load it from a CDN with a single script tag.

      

      

        
2

        
Add a container
Any element works. Plotline fills it and follows its size.

      

      

        
3

        
Describe your chart
Pass data and a spec. Scales, axes, and tooltips are inferred.

      

      

        
4

        
Update and react
Call update() with new data and watch it animate.
