Features

Everything you need to ship fast queries

Tern gives you the insights you need without the complexity of full APM solutions.

Zero-overhead analysis

Tern reads your existing slow query logs. No agents to install, no runtime overhead, no sampling.

Pattern detection

Automatically identifies N+1 queries, missing indexes, full table scans, and other common anti-patterns.

Code location mapping

Maps slow queries back to the exact line in your application code using SQL comments or stack traces.

Fix suggestions

Get actionable recommendations: index creation statements, query rewrites, and batching strategies.

CI/CD integration

Add query performance gates to your pipeline. Fail builds when new slow queries are introduced.

Multi-database support

Works with PostgreSQL, MySQL, MariaDB, and SQLite. Cloud-hosted databases fully supported.

How it works

Up and running in 60 seconds

No configuration files, no database credentials needed for basic analysis.

01

Install Tern

Single binary with no dependencies. Works on macOS, Linux, and Windows.

brew install tern-cli/tap/tern
02

Point to your logs

Tern auto-detects common log locations, or you can specify a path or stream from stdin.

tern analyze /var/log/postgresql/
03

Get recommendations

Tern surfaces the worst offenders with clear explanations and concrete fixes.

tern fix --apply
