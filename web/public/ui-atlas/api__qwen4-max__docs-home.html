Developer experience

From zero to chart in six lines.

A declarative options object, sensible defaults, and full type inference. If you can write JSON, you can build a dashboard.

  • Fully typed. Autocomplete every option, series, and event — errors caught at compile time.
  • Reactive by default. Call chart.update(data) and watch it tween smoothly.
  • Framework adapters. First-class wrappers for React, Vue, Svelte, and Solid.
revenue.ts TypeScript 
import { line } from '@charta/core';

const chart = line('#revenue', {
  data: mrr,                     // number[] | Point[]
  x: 'month',
  y: 'usd',
  smooth: true,
  gradient: ['#6366f1', '#8b5cf6'],
  tooltip: { format: 'currency' },
  animate: { duration: 800, ease: 'spring' },
});

Why Charta

Built for production, not just demos.

60fps at 100k points

Adaptive LOD rendering and an optional WebGPU backend keep massive datasets silky smooth, even on mobile.

Accessible by default

Keyboard navigation, screen-reader data tables, and WCAG-compliant palettes ship enabled — not bolted on.

Themeable to the pixel

Design tokens for every stroke, tick, and label. Dark mode, brand palettes, and CSS-variable theming built in.

Responsive & SSR-ready

ResizeObserver-driven layouts and deterministic server rendering. Charts hydrate without a flicker.

Tree-shakeable modules

Import only the charts you use. A line chart costs 4 kB; the whole kitchen sink is still just 12 kB gzipped.

Export anywhere

One call to export crisp SVG, PNG @3x, CSV, or the underlying data. Perfect for reports and print stylesheets.
