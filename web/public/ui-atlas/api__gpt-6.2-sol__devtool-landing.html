From query log to shortlist

01 — How it works

Start with a log file

Point Tern at a query log you already have. There’s no need to connect to a live database.

Group repeated queries

See queries that differ only in their parameter values together, with a call count for each pattern.

Spot slow queries averages miss

Rank patterns by 95th-percentile latency to see which queries are slow at the tail.

02 — Quickstart

Run your first report.

Once Tern is installed, replace ./queries.log with the path to your query log and run:

$ tern analyze ./queries.log
