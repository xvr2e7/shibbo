NovaCharts is an open-source, responsive, and highly customizable JavaScript charting library. Build interactive data visualizations in minutes with zero dependencies.

Get Started View on GitHub
$ npm install novacharts

Why NovaCharts?

Lightning Fast

Rendered via HTML5 Canvas, capable of handling millions of data points with buttery smooth 60fps animations.

Fully Responsive

Automatically resizes to fit any container. Perfect for complex dashboards, mobile apps, and embedded widgets.

Highly Themeable

Deeply customize colors, typography, and spacing, or use our built-in dark mode variables out of the box.

Zero Dependencies

Framework agnostic and incredibly lightweight (~12kb gzipped). Works seamlessly with React, Vue, or vanilla JS.

Quick Start

Create your first chart in seconds. Just pass a canvas context and your data configuration to the Chart constructor.

// 1. Import the library
import Chart from 'novacharts';

// 2. Get the canvas context
const ctx = document.getElementById('myChart');

// 3. Initialize and render
new Chart(ctx, {
  type: 'line',
  data: {
    labels: ['Jan', 'Feb', 'Mar', 
             'Apr', 'May', 'Jun'],
    datasets: [{
      label: 'Active Users',
      data: [1200, 1900, 1500, 
               2800, 2400, 3600],
      borderColor: '#4f46e5',
      tension: 0.4,
      fill: true
    }]
  },
  options: {
    responsive: true,
    plugins: {
      legend: { display: false }
    }
  }
});
