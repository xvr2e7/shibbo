What Tern finds

Automated detection for the database performance issues that slow down your app.

🐌

Slow query detection

Identifies queries exceeding your threshold and highlights the exact lines responsible.

🔍

Missing index suggestions

Analyzes query plans and recommends indexes to turn table scans into index seeks.

🔁

N+1 query detection

Spots loops that issue repeated queries and points you to the eager-loading fix.

🐘

Multi-database support

Works with PostgreSQL, MySQL, SQLite, and more—no drivers to install.

🚀

CI/CD ready

Run Tern in your pipeline to block regressions before they reach production.

⚙️

Zero configuration

Point Tern at your database and codebase. It handles the rest.

$ tern scan
PostgreSQL • 4 slow queries • 1 N+1 issue
$ tern scan --db postgres://localhost:5432/app --app ./src

Binary

Docker
