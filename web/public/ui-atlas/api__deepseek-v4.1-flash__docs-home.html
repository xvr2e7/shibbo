Why Lumen

Everything you need,
nothing you don't

Built for teams that care about bundle size, accessibility and getting to production quickly.

14 kB gzipped

A tree-shakeable core with zero runtime dependencies. Import only the chart types you actually render.

30+ chart types

From sparklines and bar charts to Sankey diagrams, heatmaps and financial candlesticks.

Framework agnostic

First-class wrappers for React, Vue, Svelte and Solid. Or use the plain DOM API anywhere else.

Typed end to end

Written in TypeScript with strict generics, so your data shape flows straight into autocomplete.

Accessible by default

Keyboard navigation, ARIA descriptions and WCAG AA contrast in every built-in theme.

Themeable with CSS

Every colour, radius and font is a CSS custom property. Drop in a theme or write your own in minutes.

Quickstart

Your first chart in 30 seconds

One import, one config object. Lumen handles the scales, axes, animations and tooltips for you.

revenue.js 
import { Chart } from '@lumen/charts';

new Chart('#revenue', {
  type: 'area',
  smooth: true,
  theme: 'aurora',
  data: [34, 52, 41, 68, 58, 80, 71, 94],
  labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug'],
  onHover: (point) => tooltip.show(point),
});
