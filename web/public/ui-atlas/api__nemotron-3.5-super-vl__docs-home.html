Get started in seconds

Install via npm or include directly from a CDN. No build step required.

📦 Install

npm install @aether/charts
import { Chart } from '@aether/charts';

🚀 Usage

const chart = new Chart(document.getElementById('myChart'), {
  type: 'line',
  data: {
    labels: ['Jan', 'Feb', 'Mar'],
    datasets: [{
      label: 'Revenue',
      data: [1200, 1900, 1500]
    }]
  }
});
