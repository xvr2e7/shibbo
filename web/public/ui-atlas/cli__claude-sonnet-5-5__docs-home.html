01 / declarative

Quick start

From install to chart in three steps.

No config files or build plugins required. Plotline runs in any modern bundler or straight from a CDN.

  1. Install the package

    Add plotline with your package manager, or load it from a CDN with a script tag.

  2. Add a container

    Give Plotline an element to render into. It sizes itself responsively to its parent.

  3. Describe your chart

    Call chart() with data and marks. Update later with .update().

chart.jsReactCDN
import { chart, line, axis } from 'plotline';

const data = [
  { week: 'W1', users: 1240 },
  { week: 'W2', users: 1810 },
  { week: 'W3', users: 2390 },
];

chart('#app', {
  data,
  x: 'week',
  y: 'users',
  marks: [line({ curve: 'monotone' })],
  axes:  [axis('x'), axis('y', { grid: true })],
});
// → an interactive, accessible line chart
