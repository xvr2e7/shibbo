      Quick start
      
From empty file to chart in three steps

      
    
        
  1. Install the package
    Run npm install ordinate, or load the ES module from any CDN that mirrors npm.
    2. 
        
  2. Give it somewhere to draw
    Any element works. The chart fills its container and re-renders when the container resizes.
    3. 
        
  3. Describe the chart
    Pass your rows and say which fields map to x and y. Scales, axes and a tooltip are inferred.

Design principles
What you can rely on

    

    

      

        
        
Accessible by default

        
Keyboard navigation, generated text summaries, and pattern fills that don't rely on colour alone. No extra configuration.

      

      

        
        
SVG or Canvas, one API

        
Start with crisp, styleable SVG. Switch to renderer: 'canvas' when you pass a hundred thousand points.

      

      

        
        
Pay for what you import

        
Every chart type and plugin is a separate export. A single line chart ships in about 6 kB.

      

      

        
        
Themed with plain CSS

        
Colours, type and spacing are custom properties. Dark mode is a media query, not a second config object.
