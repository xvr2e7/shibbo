Zero-config database profiler

Find slow queries
before they find your users.

Tern is a command-line tool that watches your database traffic, catches bottlenecks, and tells you exactly how to fix them. No heavy agents, no code changes.

Also available via brew, npm, and go install

Built for developers who ship.

No bloated APM dashboards. Just the answers you need, right in your terminal.

Instant N+1 Detection

Tern clusters identical queries fired in rapid succession, instantly exposing ORM inefficiencies before they ever hit production.

Plain-English EXPLAIN

We parse EXPLAIN ANALYZE output and translate cryptic database jargon into actionable fixes you can actually understand.

Wire-level & Agnostic

Works with PostgreSQL, MySQL, and SQLite. Node, Python, Go, or Ruby—if it talks to a DB, Tern watches it without a single line of instrumentation.
