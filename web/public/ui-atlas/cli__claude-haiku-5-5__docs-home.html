Why Chartwright

Everything a chart needs, nothing it doesn't.

Built for teams that want good-looking data visualization without a heavy framework or a sprawling configuration surface.

⚡

Fast by default

Renders to SVG or Canvas with incremental updates. Only the changed pixels are touched, so 100k-point series stay smooth.

{ }

Declarative API

Describe what you want to see as plain data. Chartwright infers axes, ticks, legends, and tooltips from the shape of your input.

◎

Accessible

Semantic markup, ARIA descriptions generated from your data, keyboard navigation between points, and respect for reduced-motion settings.

▦

18 chart types

Line, area, bar, stacked, scatter, bubble, donut, heatmap, box plot, and more. All share one consistent API and theme system.

✦

Themeable

Ships with light and dark themes that follow the system setting. Override any token with CSS custom properties.

⬡

Framework-friendly

Works in plain HTML, React, Vue, Svelte, and server-rendered pages. Typed with TypeScript and tree-shakeable.

Quick start

From data to chart in three lines.

Import the library, point it at an element, and pass your data. Sensible defaults take care of the rest, and every option is documented when you need it.

  • ✓Install from npm or load it from a CDN.
  • ✓Render with a single function call.
  • ✓Customize colors, scales, and interactions as you need them.
import { chart } from "chartwright";

// Describe the data. The type infers the axes.
const view = chart("#revenue", {
  type: "line",
  x: "month",
  y: "revenue",
  data: [
    { month: "Jan", revenue: 42 },
    { month: "Feb", revenue: 58 },
    { month: "Mar", revenue: 51 },
    { month: "Apr", revenue: 73 },
  ],
  smooth: true,
});

// Update in place. Transitions are animated automatically.
view.update({ data: nextQuarter });
