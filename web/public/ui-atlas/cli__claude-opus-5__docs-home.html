Why Plotline

A small API with a high ceiling

Every chart is the same object: { type, data, options }. Learn it once, and the other twenty-three chart types are already familiar.

12 kB, really

The core plus the SVG renderer is 12.4 kB gzipped. Import only the chart types you use and tree-shaking takes it under 6 kB.

Two renderers, one config

Ship crisp, inspectable SVG by default. Switch to canvas for 100k+ points without rewriting anything.

Framework agnostic

A plain class that owns a DOM node. First-party wrappers exist for React, Vue, Svelte and Solid — all thin, all optional.

Accessible by default

Charts render with roles, labels and a keyboard-navigable data table fallback. Color palettes ship contrast-checked.

Themeable with CSS

Colors, grids and type are CSS custom properties. Dark mode is a data-theme attribute away — no re-render required.

Typed end to end

Options narrow on type, so a bar chart will never autocomplete curve. Written in TypeScript, published with source maps.

Quick start

Your first chart in sixty seconds

Install the package, point it at an element, hand it some data. There is no build-step plugin, no registration step, and no global configuration file.

$ npm install plotline
revenue-chart.ts
import { Chart } from 'plotline';
import 'plotline/theme.css';

const chart = new Chart('#revenue', {
  type: 'bar',
  data: {
    labels: ['Q1', 'Q2', 'Q3', 'Q4'],
    series: [
      { name: 'Direct',  values: [18, 24, 31, 42] },
      { name: 'Partner', values: [12, 15, 14, 23] }
    ]
  },
  options: {
    stacked: true,
    axis: { y: { format: (v) => `$${v}k` } },
    legend: 'top'
  }
});

// later: push new data, keep the animation
chart.update(nextQuarter);
1

No registration. Chart types are resolved from the type field and bundled only when referenced.

2

Resize is automatic. A single shared ResizeObserver handles every chart on the page.

3

Updates are diffed. chart.update() tweens from the current geometry instead of tearing down the DOM.

Chart types

Twenty-four types, one mental model

Each of these is rendered on this page by the same engine. Open any card for the full source, the options reference, and an editable playground.

Line & area

type: 'line'

Linear, step, and monotone curves. Stack areas, mark thresholds, or annotate gaps in the data.

Bar & column

type: 'bar'

Grouped, stacked, or 100%-stacked. Horizontal is a one-word change to orient.

Pie & donut

type: 'donut'

Arc padding, center content, and automatic label collision handling for small slices.

Scatter & bubble

type: 'scatter'

Quantitative axes, size encoding, regression overlays, and quadtree-accelerated hit testing.

Heatmap

type: 'heatmap'

Categorical or time-binned matrices with sequential, diverging, and custom color scales.

Sparkline

type: 'spark'

Axis-free micro charts built for tables and dashboards. Renders in under a millisecond.
