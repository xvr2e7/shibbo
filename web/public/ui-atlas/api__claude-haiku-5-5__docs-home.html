Why Plotline

        
Everything a chart needs. Nothing it doesn’t.

        
Built for product teams and data developers who want good defaults without giving up control.

      


      

        

          

          
Declarative specs

          
Describe what you want to see as plain JSON or typed objects. The library handles scales, ticks, and layout.

        

        

          

          
Responsive by default

          
Charts resize with their container, reflow axis labels, and adapt margins without a single media query.

        

        

          

          
Accessible

          
Keyboard navigation, ARIA summaries, and high-contrast palettes ship on every chart type out of the box.

        

        

          

          
Fast at scale

          
Switch to the WebGL renderer for datasets with millions of points while keeping the same API.

        

        

          

          
Themable

          
Design tokens map to CSS custom properties, so charts follow your light and dark modes automatically.

        

        

          

          
Zero dependencies

          
Under 30 KB gzipped, tree-shakable, and works with React, Vue, Svelte, or plain HTML.
