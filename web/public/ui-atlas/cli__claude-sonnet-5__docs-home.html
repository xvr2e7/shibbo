Everything you need, nothing you don't

Plotix ships as a single dependency-free core with opt-in plugins, so your bundle only grows when you ask it to.

Canvas & SVG renderers

Switch between a buttery-fast canvas renderer or a fully inspectable SVG tree with one config flag.

Live data streaming

Push new points into a chart at 60fps without re-mounting or re-parsing your dataset.

25+ chart types

Line, bar, candlestick, radar, heatmap, Sankey, and more — all sharing one consistent API.

Buttery animations

Spring-based transitions driven by a dedicated timing engine, tuned for 120Hz displays.

Accessible by default

Keyboard navigation, screen-reader descriptions, and color-blind-safe palettes out of the box.

Framework adapters

First-party bindings for React, Vue, and Svelte — or use the vanilla core anywhere.

Pick a shape, any shape

Every chart type shares the same declarative options object — learn one, use them all.

chart.config.js 
import { Plotix } from 'plotix';

const chart = new Plotix('#canvas', {
  type: 'line',
  data: {
    labels: ['Mon', 'Tue', 'Wed', 'Thu'],
    series: [{
      name: 'Revenue',
      values: [12, 19, 14, 25],
      smooth: true,
    }],
  },
  theme: 'midnight',
});

// stream a new point in real time
chart.push('Revenue', 31);

A config object, not a framework

No wrapper components to fight, no proprietary DSL — just plain objects and a predictable API that reads the same whether you're writing vanilla JS or a thin React hook.

  • Zero runtime dependencies, ~11kb gzipped core
  • TypeScript types generated from the same schema as the docs
  • Server-side rendering support for static exports
  • Plugin hooks for custom tooltips, annotations, and axes
