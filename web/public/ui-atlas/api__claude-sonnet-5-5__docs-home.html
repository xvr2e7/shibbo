Charts that stay out of your way.

Chartreuse is a small, accessible, open-source charting library for the web. Describe your data and marks; get fast, beautiful, keyboard-friendly charts in SVG or Canvas — with no framework lock-in.

Quick start#

From zero to your first chart in three steps. Chartreuse works with plain JavaScript and has first-class bindings for popular frameworks.

Full tutorial →

Install the package

Add chartreuse from npm, or load the ES module from a CDN.

Add a container

Give the chart an element to live in. It resizes with its parent automatically.

Describe your chart

Pass data and a list of marks. That's the whole API.

import { Chart, Line, Axis, Tooltip } from 'chartreuse';

const data = await fetch('/api/visits.json').then(r => r.json());

new Chart('#root', {
  data,
  x: 'month',
  marks: [
    Line({ y: 'visitors', curve: 'monotone' }),
    Line({ y: 'signups',  curve: 'monotone' }),
  ],
  axes:    [Axis.x(), Axis.y({ grid: true })],
  plugins: [Tooltip()],
});
import { Chart, Line, Axis, Tooltip } from 'chartreuse/react';

export default function Traffic({ data }) {
  return (
    <Chart data={data} x="month" height={320}>
      <Line y="visitors" curve="monotone" />
      <Line y="signups"  curve="monotone" />
      <Axis.Y grid />
      <Tooltip />
    </Chart>
  );
}
<script setup lang="ts">
import { Chart, Line, Axis, Tooltip } from 'chartreuse/vue';
defineProps<{ data: Visit[] }>();
</script>

<template>
  <Chart :data="data" x="month">
    <Line y="visitors" curve="monotone" />
    <Line y="signups" curve="monotone" />
    <Axis.Y grid />
    <Tooltip />
  </Chart>
</template>

Why Chartreuse#

Designed around a small core, sensible defaults, and the belief that every chart should be usable by everyone.

Tiny & tree-shakeable

The core is 14 kB gzipped. Import only the marks you use and ship nothing else.

Accessible by default

Keyboard navigation, ARIA labels, high-contrast palettes and an automatic data-table fallback.

SVG or Canvas

Swap renderers with one option. Crisp vectors for print, GPU-friendly canvas for a million points.

TypeScript-first

Fully inferred types from your data shape, so field names and scales autocomplete in your editor.

Streaming data

Append points from WebSockets or SSE and let the chart animate smoothly without re-rendering.

Themeable with CSS

Every color, font and spacing value is a CSS custom property. Dark mode takes one line.

14 kBcore, gzipped
32built-in marks
1M+points at 60 fps (Canvas)
MITlicensed, forever
