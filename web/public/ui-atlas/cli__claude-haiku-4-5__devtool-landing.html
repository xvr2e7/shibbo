Find Slow Database Queries Fast

Tern is a command-line tool that identifies performance bottlenecks in your database queries with comprehensive analysis and actionable insights.

View Docs
# Analyze your database queries
$ tern analyze --database myapp.db

# Results show exactly where to optimize
Query: SELECT * FROM users JOIN orders...
Execution Time: 2847ms ⚠️ SLOW
Missing Index: users.order_id
Suggestion: CREATE INDEX idx_order_id ON users(order_id)

How It Works

1

Connect

Point Tern to your database with a connection string or environment variable.

2

Analyze

Run analysis to profile queries and identify performance issues automatically.

3

Optimize

Follow recommendations to add indexes, optimize queries, and improve speed.

4

Monitor

Track improvements and run periodic checks to maintain optimal performance.

Get Started in Seconds

# Install Tern
brew install tern

# Or via npm
npm install -g @tern/cli

# Analyze your database
tern analyze --database postgres://user:pass@localhost/myapp

# Get a detailed report
tern report --format json --output results.json
