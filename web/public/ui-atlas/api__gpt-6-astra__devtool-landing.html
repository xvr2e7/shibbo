TERN / QUICK START

Meet your faster database.

Install Tern, then analyze your database using a connection string. Use a read-only database account and keep credentials out of your shell history.

1. Install

brew install tern

2. Analyze

tern analyze --db "$DATABASE_URL"

Set DATABASE_URL to your PostgreSQL or MySQL connection string. Review Tern’s recommendations before applying changes. Tern never modifies your database.
