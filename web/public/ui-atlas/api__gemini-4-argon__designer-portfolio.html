03 // Operating Theses
HOW I APPROACH PRODUCT ARCHITECTURE
THESIS 01 // SPEED IS AN EMOTION

Sub-50ms perceived latency

Enterprise software shouldn’t feel punitive. Optimistic UI updates, keyboard-first command palettes, and zero-layout-shift skeletons turn daily repetitive workflows into effortless muscle memory.

THESIS 02 // SYSTEMS OVER ARTIFACTS

Design in tokens & constraints

Static mockups decay the moment they are handed off. I work directly in the gap between Figma variables and production CSS/React—ensuring edge cases, truncation, and dark modes are solved structurally.

THESIS 03 // AI WITH PROVENANCE

Inspectable intelligence

Users don't trust black-box magic in high-stakes workflows. AI interfaces must expose confidence intervals, inline source citations, and non-destructive undo pathways at every step.
