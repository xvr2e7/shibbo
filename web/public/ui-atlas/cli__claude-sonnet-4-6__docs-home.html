Why Luminary

Designed for the way you actually build

A clean, composable API that gets out of your way — whether you're wiring up a quick prototype or building a production analytics dashboard.

⚡

Declarative & composable

Describe your chart with data and options. Luminary handles rendering, scaling, and layout automatically.

🎨

Fully themeable

Built-in dark & light themes, plus a first-class theming API. Every visual token is overridable.

📐

Responsive by default

Charts observe their container and re-render on resize. No manual width/height management needed.

♿

Accessible

ARIA labels, keyboard navigation, and screen reader summaries are built in, not bolted on.

🔌

Framework agnostic

Works with React, Vue, Svelte, Solid, Angular, and vanilla JS via a universal Web Component wrapper.

dashboard.tsx 
import { Chart, Line, XAxis, YAxis, Tooltip }
  from 'luminary-charts';

const data = [
  { month: 'Jan', revenue: 4200, users: 1800 },
  { month: 'Feb', revenue: 5800, users: 2100 },
  { month: 'Mar', revenue: 7400, users: 3300 },
  // ...
];

export function RevenueDashboard() {
  return (
    <Chart
      data={data}
      theme="dark"
      height={320}
    >
      <XAxis dataKey="month" />
      <YAxis tickFormatter={formatUSD} />
      <Tooltip />

      <Line
        dataKey="revenue"
        color="violet"
        strokeWidth={2}
        dot
      />
      <Line
        dataKey="users"
        color="teal"
        dashed
      />
    </Chart>
  );
}
