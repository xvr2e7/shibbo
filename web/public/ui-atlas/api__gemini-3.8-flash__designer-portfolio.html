Operating Principles

How I tackle ambiguity

A systematic framework honed over a decade of partnering with founding teams and scaling enterprise products.

01 / DISCOVERY

Information Topology

Before drawing pixels, I map the structural ontology of the problem. What are the canonical objects, their lifecycles, and relational mutations? Good architecture emerges when objects mirror real mental models.

02 / PROTOTYPING

High-Fidelity Pressure Tests

Static screens lie. I validate hypotheses with code-based prototypes using realistic datasets, high latency, edge states, and error cascades. If it doesn't hold up in motion, it isn't ready for users.

03 / CONTINUITY

Design As a Compound Asset

A design system is an enterprise asset, not a Figma file. I design with automated token pipelines, strict semantic roles, and cross-functional documentation that keeps engineering velocity high indefinitely.
