Beautiful Charts Made Simple

A modern, lightweight JavaScript library for creating stunning data visualizations. Open source, fully customizable, and easy to integrate.

Get Started → View Examples 
// Create a chart in seconds
import { ChartFlow } from 'chartflow';

const chart = new ChartFlow('#chart', {
  type: 'line',
  data: {
    labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
    datasets: [{
      label: 'Revenue',
      data: [12, 19, 3, 5, 2, 3]
    }]
  },
  options: {
    responsive: true,
    animation: true
  }
});

Get Started in Minutes

1

Install

Add ChartFlow to your project using npm, yarn, or CDN.

npm install chartflow
2

Import

Import the library into your JavaScript or TypeScript file.

import ChartFlow from 'chartflow';
3

Create

Initialize a chart with your data and configuration.

new ChartFlow('#chart', config);
