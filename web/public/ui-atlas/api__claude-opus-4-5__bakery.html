An Odd Name, An Honest Loaf

We started Odd Loaf in 2019 with one wild sourdough starter and a dream of baking bread the way it should be made — slowly, simply, with care.

Every loaf that leaves our oven is a little different. Some rise higher, some have bigger bubbles. We think that's beautiful. That's why we're Odd Loaf.
